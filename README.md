# ARC UAE – HVAC Project

## Project Overview
This project focuses on HVAC system layouts and mechanical equipment arrangements for the ARC Project in the UAE.

## Key Components
- Supply and return air ducting
- Fresh air duct system
- Fan Coil Unit (FCU) placement
- HVAC equipment arrangements
- Duct routing and MEP coordination

## Software & Tools
- AutoCAD
- Microsoft Excel
- Revit MEP (where applicable)

## Project Documentation
This repository contains HVAC drawings, equipment layouts, project screenshots and related technical documentation.

## Objective
To develop practical knowledge of HVAC layouts, ducting systems, equipment placement and MEP coordination.
